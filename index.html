    O problema

    Quem deixa o celular na assistência ou o carro na oficina fica sem saber se já chegou, se está em análise ou se está pronto. Liga, manda mensagem, volta lá. O dono perde horas respondendo “e o meu?”.

    RASTREIA é o rastreio de serviço, como o de uma encomenda: o dono muda a etapa e o cliente vê pelo link, sem instalar nada e sem criar conta.

    Regras

    • 14 dias para entregar um MVP funcional.
    • R$ 0 de orçamento: planos free de Supabase e GitHub Pages.
    • Mesma stack: HTML, CSS, JavaScript, Supabase (Auth, Realtime, RLS) e GitHub.
    • Dois repositórios públicos, um por dev, com commits diários.
    • Nada de segredos: nunca mostre chaves, senhas ou dados reais de clientes.
    • Dados de clientes: aviso de privacidade simples e opção de apagar dados (LGPD).

    Combinado entre os dois

    Antes da primeira linha de código, registrem por escrito:

    • Quem é dono de cada implementação do código.
    • Como ficam receita, despesas e prêmio se o produto faturar.
    • Quem dá suporte e corrige falhas depois do desafio.
    • O que acontece se alguém sair do projeto.
